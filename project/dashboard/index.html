How it works

Show architecture & guardrails
  • LLM chooses each step; our code only runs the tool it asks for.
  • Output is cut at “Observation:” so the LLM cannot invent tool results.
  • Unknown tool / bad format → ERROR observation, LLM self-corrects.
  • Hard limit of 10 steps. Calculator uses safe ast, never eval.
  • Every event is logged to logs/*.jsonl with timestamps.
